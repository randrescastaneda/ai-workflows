# Example Delta Brief

Use this structure after meaningful changes to a target repository.

## 1. Summary of Changes

Briefly summarize what changed since the last repo brief.

## 2. Sections of the Existing Repo Brief That Are Now Stale

List affected sections and why they are stale.

## 3. New Facts to Add

Add new source-backed facts.

## 4. Facts to Remove or Revise

Identify outdated, misleading, or incomplete statements.

## 5. New Open Questions

List questions that require maintainer confirmation.

## 6. Suggested Patch to `repo-brief.md`

Provide replacement text for affected sections only.

## 7. Source Evidence

List files or commits consulted and what each supported.
